**Pagos de Stellar en dispositivos IoT.** Stellar MCU SDK es una librería abierta para que un
microcontrolador cobre, confirme y firme pagos en [Stellar](https://stellar.org), sin un servidor
en el medio. Es una librería para microcontroladores, no para un chip: el núcleo es C99 portable, y
el ESP32 es el primero. Está hecha por [Paizap](../).

Es para quienes construyen dispositivos IoT que cobran: integradores y fabricantes de máquinas, y los
proyectos de Stellar que trabajan con hardware.

## Qué hace

| | Qué hace el aparato |
|---|---|
| **Cobrar** | Arma el pedido de pago (SEP-7) que entienden las billeteras, para mostrarlo como QR. |
| **Confirmar** | Le pregunta a un nodo de Stellar RPC y comprueba él mismo que el pago llegó, con su monto y su número de pedido. |
| **Pagar** | Guarda su llave, arma la transacción, la firma y la envía: un pago común o una llamada a un contrato de token (`transfer`, `transfer_from`). |

## Cómo se ve

Un pago, de principio a fin, desde el microcontrolador:

```c
stl_tx t = {0};
memcpy(t.source, public_key, 32);
t.fee = 100;
t.sequence = sequence + 1;              // leída del nodo con getLedgerEntries
t.valid_until = close_time + 120;       // la hora la da el nodo: no hace falta reloj propio
t.has_memo = true;
t.memo = 4242;                          // el número de pedido

stl_xdr x;
uint8_t hash[32];
stl_tx_begin(&x, envelope, sizeof envelope, network_id);
stl_tx_payment(&x, &t, destination, NULL, 10000000);   // 1 XLM
stl_tx_sign(&x, &CRYPTO, seed, public_key, hash);      // firma en el aparato
// ...y el sobre va en base64 a sendTransaction
```

El código y sus comentarios están en inglés; esta documentación, en español.

## Qué está comprobado

- El núcleo pasa **23 de 23 comprobaciones** en el PC; 16 comparan **byte a byte** lo que arma
  con el SDK oficial de JavaScript.
- El primer microcontrolador, un ESP32-S3, **pagó solo en testnet** y después detectó sus pagos
  en los eventos de la red.
- Un terminal con tarjeta NFC **firma sus cobros** con el SDK. Es
  [la demo de Paizap](./demo-terminal/).
- El núcleo ocupa **3,4 KB** y la firma, **18 KB**. Firmar tarda **7 milisegundos** y un pago queda
  confirmado en **3 a 6 segundos**.

El detalle de cada cifra está en [Medidas](./referencia/medidas/).
